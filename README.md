## Hướng dẫn khởi chạy nhanh
1. Giải nén thư mục dự án.
2. Mở terminal tại `backend`, chạy `npm install` (nếu chưa có `node_modules`), sau đó chạy `npm run seed` và `npm run dev`.
3. Mở terminal thứ 2 tại `frontend`, chạy `npm install` và `npm run dev`.
4. Hoặc trên Windows, chạy `powershell -ExecutionPolicy Bypass -File .\start-all.ps1`.
